# Cafe 24/7

## Как запустить

Откройте `index.html` в браузере. Можно выбирать категорию, добавлять или убирать напитки и оформлять заказ.

## Принципы ООП

- **Абстракция:** `Drink` задаёт общие свойства и методы, но не создаёт экземпляры напрямую.
- **Инкапсуляция:** приватное поле `#temperature` доступно через `getTemperature()` и изменяется методом `setTemperature()` с проверкой значения.
- **Наследование:** классы `Coffee`, `Tea` и `Lemonade` наследуют `Drink`.
- **Полиморфизм:** каждый тип напитка по-своему реализует `prepareRecipe()`, который вызывается приватным `#prepare()` при подаче.
- **Кафе:** `Cafe` принимает название и адрес, `getInfo()` возвращает информацию о кафе, а `orderDrink(drink)` принимает напиток, вызывает его `serve()` и записывает процесс в консоль.
- **Заказ:** выбранные напитки добавляются в корзину, а при оформлении для каждого вызывается `Cafe.orderDrink()`.
- Общие методы напитков: `getInfo()`, `getTemperature()`, `setTemperature()` и `serve()`. `serve()` готовит напиток и выводит этапы приготовления и подачи в консоль.
- Логика приложения находится в `main.js`.
