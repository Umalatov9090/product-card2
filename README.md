# product-card2

## Структура JavaScript

- `main.js` — единственная точка подключения скриптов в `index.html`; остальные учебные скрипты запускаются через side-effect imports.
- Модель каталога использует наследование: класс `Product` в `Product.js` → `BeautyProduct` в `beautyProduct.js` → `GiftSet` в `giftSet.js`. Карточки в `products.js` создаются как экземпляры этих классов.
- `Modal.js` и `Form.js` содержат классы управления модальным окном и формой регистрации; их использует задание №11.
- В обработчиках событий, которым нужен `this` экземпляра, используем стрелочные функции; обычные методы передаём отдельно только с привязкой контекста через `bind`.
